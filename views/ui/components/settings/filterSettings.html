Placeholder reference

Patterns can use placeholders that are replaced with the show's data. A number placeholder can include a zero-pad width, e.g. {season:00}.

{alias}Show name or alias used for the search
{show}Canonical show name
{season}Season number
{episode}Episode number
{season:00}Season number zero-padded, e.g. 01
{episode:00}Episode number zero-padded, e.g. 05
{absolute}Reserved, not implemented yet

Example: {alias} S{season:00}E{episode:00} becomes dbz S01E04.

search patterns build the Prowlarr query; required, rejected and preferred patterns are matched against the release filename.
